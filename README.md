# Kioskassignment

## 목표

### - 단순 구현사항에만 집중하는 것은 지양

### - 객체지향 설계(캡슐화, 상속, 추상화, 다형성)에 대한 고민

### - 클래스에 대한 개념 이해 및 객체 지향 개념의 적용


## 필수 과제 : Lv 1 ~ 5

### - Main, Kiosk, Menu, MenuItem 총 4가지의 클래스를 활용하여 객체 지향 프로그래밍 하기

### - level1to5 패키지


## 필수과제 구현 사항

### Lv 1

#### 사용한 기능

##### - 반복문(for, while문), 조건문(if, switch문)

##### - Scanner

### Lv 2

#### 사용한 기능

##### - 반복문(for, while문), 조건문(if, switch문)

##### - Scanner

##### - 컬렉션(List)

#### 업데이트 사항

##### - MenuItem 클래스를 생성하여 캡슐화 후 getter와 setter를 추가하였음

##### - 리스트를 생성하고 리스트에 MenuItem 객체를 넣어 관리하였음

##### - for문과 리스트의 get() 기능, MenuItem 클래스의 getter 기능 등을 활용하여 메뉴판을 출력하였음

##### - switch문에 if문과 while문을 활용하여 번호를 잘못 입력하였을 때 다시 입력하게 하였음(예외처리는 아직 하지 않음)

#### Lv 1, 2에 대한 내용 및 회고는 https://couchpo.tistory.com/41 참고

### Lv 3

#### 사용한 기능

##### - 반복문(for, while문), 조건문(if, switch문)

##### - Scanner

##### - 컬렉션(List)

##### - 예외처리(try-catch)

#### 업데이트 사항

##### - Kiosk 클래스 추가

##### - main메서드에서 관리하던 menuItemList를 Kiosk에서 관리(생성자)

##### - 문자열 입력했을 때 생기는 예외 처리

#### Lv 3에 대한 내용 및 회고는 https://couchpo.tistory.com/42 참고

### Lv 4, 5

#### Lv 5의 요구사항이 캡슐화였으므로 Lv 4와 같이 묶어서 진행하였음

#### 사용한 기능

##### - 반복문(for, while문), 조건문(if문)

##### - Scanner

##### - 컬렉션(List)

##### - 예외처리(try-catch)

##### - 클래스 메서드

#### 업데이트 사항

##### - Menu 클래스 추가 

##### - Kiosk 클래스에서 관리하던 menuItemList를 Menu 클래스에서 관리(메서드, 생성자) 및 category 필드 추가

##### - 예외처리 부족한 부분 보완

##### - 중복코드 메서드로 관리

##### - Lv 3에서 생성자에 넣어줬던 List들을 관리하는 메서드 추가

##### - 카테고리 선택에서 0을 입력 할 경우 가장 상위의 while문을 빠져나가기 위해 가장 상위의 while문에 이름을 붙였음

#### Lv 4, 5에 대한 내용 및 회고는 https://couchpo.tistory.com/44 참고
